# Home Shooting - A 2D Top-Down Android Game

Welcome! I am a 12-year-old developer building a 2D top-down game using **Pygame-CE (Community Edition)**. 
The goal is to expand the foundations and eventually publish this game completely for free on the Google Play Store.

## Project Vision
* **Engine:** Pygame-CE (We are strictly using the Community Edition due to the orignal library isn't that compatable with Android)
* **Platform:** Android (Targeting deployment via buildozer)
* **License:** GNU GPLv3 (Copyleft)
* **Monetization:** Completely free, no ads, no paywalls.
* **Usage:** Anybody may take any stable APK, install it on Android and play it.

### How to Help
I am looking for community help to improve the code base, fix bugs, and build features. 

Because I am keeping a creative control over the project, **all contributions must be submitted via Pull Requests** for me to review and approve.

Keep comments simple: # After the hash, keep one space before starting the comment. The first letter of a sentence should ALWAYS be capital.

## How to Run Locally
1. Clone this repository.
2. Install the correct library: `pip install pygame-ce` (Do not install standard pygame!)
3. Run `python main.py`
4. **NOTE:** The syntax for pygame-ce is identical to the standard pygame. **Do not use "pygame-ce" in the code!**
